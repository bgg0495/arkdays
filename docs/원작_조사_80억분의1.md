# 원작 조사: 「80억 분의 1」 작동 파이프라인

조사일 2026-10-19 · 조사 대상 v0.7.75 베타 (https://1in8b.life/ko/)
방법: 실제 플레이 관찰(탄자니아 남성 1회차, 0세→81세), 런타임 상태 객체 덤프, 번들 JS(`/a/ko.<hash>.js`, 약 3.1MB·28,539줄·비압축) 정적 분석, 기사·나무위키·이용 안내 검토.

> 주의: 이용 안내(2026-10-23부터 명시)에 따르면 코드·텍스트·그림은 운영자 저작물이고 복제·수정·재배포가 금지된다. "실제 통계로 한 삶을 살아 본다"는 아이디어 자체는 누구의 것도 아니므로 자유롭게 새 작품을 만들어도 된다고 안내함. 패러디는 **구조와 아이디어만** 가져오고 문구·에셋·코드는 전부 새로 만든다.

## 0. 한눈에 보는 파이프라인

```
[랜딩/설정] ──태어나기──▶ [출생 신고서] ──삶을 시작하기──▶ [인생 화면: rAF 루프]
   세상(지난/지금/다가올/아무)       국가·성별·도시·가정 분위·            매 프레임 t += dt/yearSec
   추첨 기준(출생/인구)               종교·부모·형제·동행자 4명 생성       연 경계마다 tick(연 1회 처리)
   길이(30/60/90분)                   공유 카드(출생)                       이벤트 큐 소비 → 로그·스탯 반영
   실제 출생국(비교용)                                                        결정 모달(중대/작은/잠시 멈춤)
                                                                                 │ deathAt 도달
                                                                                 ▼
                                                               [마지막 순간 시네마틱] → [사망 기록]
                                                               픽셀 장면 8컷 + 자막          요약문·사인·통계 비교·
                                                                                              16가지 "결"·돌아보며·
                                                                                              오늘의 주제·공유·추모관·
                                                                                              간직하기(유료)·다시 태어나기
```

핵심 설계 요약:
- **단일 페이지, 단일 전역 상태 `S`**: 모든 화면(랜딩·출생·인생·사망)이 한 HTML 안에 있고 `phase`(`birth`→`life`→`dead`)로 전환.
- **시간 = requestAnimationFrame**: `frame(now)` → `frame0(now)` 반복. 연(年) 단위로 시뮬레이션이 진행되고, 실시간 ↔ 게임 시간 비율은 `yearSec`(1시간 설정 시 약 55초/년)과 `speed`(1~16×)로 결정. 탭이 숨겨지면 멈춘다(rAF 특성).
- **통계 → 확률**: 172개국 테이블에서 출생국을 뽑고, 그 나라 지표(기대수명·5세 미만 사망률·GDP·지니·교육연수·HIV·살인율 등)가 모든 확률의 기준이 된다. 사망 시점은 생명표, 사인은 WHO/GBD 지역·연령 패턴.
- **이벤트 큐 + 플래그 사전**: 한 해 안에서 `queue[{at: 0~1, type, id}]`를 소비. `flags.ev_<id>`(마지막 발생 나이), `flags.roll_<id>`(다음 굴림 나이), `recent[]`(최근 이벤트 반복 방지), `done{}`(결정 횟수)으로 중복·간격 제어.
- **결정은 모달 3종**: `중대 결정`(진학·취업·결혼·은퇴 등, 효과 힌트 표시) / `작은 선택`(동창회 등, 몇 초 뒤 기본값 자동 선택) / `잠시 멈춤`(5·15·30·50·70세, 질문 + 한 줄 입력).
- **동행자 4명은 사전 계산**: 출생 시 같은 엔진으로 끝까지 돌려 `comps[i].yrs[]`(나이별 한 줄 상태)와 `death`를 미리 저장하고, 매년 해당 줄만 보여 준다. 실시간 병렬 시뮬레이션이 아니다.
- **규모(실측)**: 국가 172 × 35필드, 이름 클러스터 약 90, 직업 71, 사인 33 × (지역 7 × 연령대 7) 가중표, 피드 이벤트 `EVENTS` 188, 결정 `DEC` 147, 돈쓰기 `SHOP` 약 50, 역사 `HIST` 168, 따뜻한 순간 `WARM`·작은 선택 `SMALL`·사람 이야기 `HUM` 별도. 외부 라이브러리 0, 외부 이미지 0(픽셀 아트·음악 전부 코드 생성).
- **저장 = localStorage**: `one8b.save.v3`에 `{S, at}` 통째로(약 32KB). 서버는 집계·공유·추모관·결제에만 쓴다.

## 3. 인생 화면 (phase = life)

### 3.1 레이아웃
- **상단 바**: 제목 · 나이(큰 글씨) · 연도 · 이름 · `1년 ≈ N초` · 멈춤 · 배속 1/2/4/8/12/16× · `다음 결정까지 »`(결정 전까지 고속 진행) · 자동 결정 · 음악 · 생각 남기기(5·15·30·50·70세 창 토글) · 밝기 · 의견 보내기 · 나가기.
- **좌측 "신원 기록" 카드**(여권 스타일): 픽셀 초상, 성별·출생·거주·종교·출신 가정(●●●●○)·학력·직업·기질, 하단에 MRZ 흉내 문자열(`I<TZAHAMISI<<SHABANI<<<` / `260301MTZA<018<<<` — 생년월일·성별·국가·나이 인코딩). 장식 배경은 `guilloche`(지폐 무늬) 캔버스.
- **상태 4종(0–100)**: 건강(`st.hl`), 행복(`st.h`), 지식(`st.sm`), 관계(`st.so`). 막대 그래프. "상태는 무엇을 뜻하나요?" 설명 팝오버.
- **돈**: 순자산(한국 체감 원 + PPP $), 연 소득(+월), 소득 위치("탄자니아 상위 48% · 세계 하위 12%"), 지난 1년 순자산 변동 내역(번 돈에서 남긴 돈/경조사비/취미 비용/…), 가진 것(예금·집·차), 다니는 길(통근 수단), 한 해 소득이 나가는 곳(세금/식비/주거/교통/의료/기타/저축 %), "금액은 어떻게 셈하나요?".
- **돈 쓰기 · 투자 패널**(15세 이후): 구매·여행·취미·이사·자격증, 여유자금 굴리기, 경조사비·보험·식습관·주기적 지출 자동 설정.
- **가족과 삶**: 어머니/아버지(나이·직업·별세·부재), 형제자매, 나를 키우는 어른, 배우자, 자녀, 친구("무난한 사이"→"가까운 사이"), 취미(`축구 Lv.4`), 거주 한 줄("도도마 · 아파트 · 외할머니와 함께").
- **픽셀 아트 장면**: 매년 `years[a].sc` 문자열로 묘사. 형식 `"1|flat|toys|0|0|0|parF28s4,meM0s4,sibM4s4|"` = (버전|집 유형|소품|…|등장인물 목록[역할+성별+상대나이+피부톤]). 집·소품(toys/school/stall/sign/truck/bench)·인물이 상황에 따라 바뀐다.
- **올해의 초점** 칩(6세 이후, 언제든 변경): 
  - 학생: 공부(지식↑ 행복↓) / 친구·놀이(관계↑ 행복↑) / 집안 돕기(가족↑ 지식 조금↓) / 운동(건강↑) / 취미(행복↑ 취미 실력↑)
  - 직장인: 일에 몰두(소득·승진↑ 건강·관계↓) / 균형 / 가족·친구(관계↑ 행복↑) / 건강 관리(건강↑ 돈 조금↓) / 자기계발(지식↑ 이직 제안↑) / 취미
  - 상태: `focus`, `fT{focus: 비율}`, `focusW{}`; 자동 결정 중엔 알아서 고름.
- **인생 기록**(로그, 최근순, 줄 누르면 ☆ 즐겨찾기 → 엔딩 컷에 우선 반영): 각 줄 = 나이 + 본문 + (선택) 출처 각주 + (선택) 효과. `log[]` 항목 `{a, text, kind, fx?, fact?, d?, act?, star?}`. kind 분포(81년 기준): `ev` 55, `warm` 23, `big` 16, `dec` 15, `bad` 12, `ms`(마일스톤 "N세. 같은 해 태어난 남자아이 중 약 92%가 지금도 살아 있습니다") 4, `loss` 2, `note` 2, `ledger` 1, `death` 1.
- **같은 1초에 태어난 사람들**: 4명의 현재 한 줄("가족을 돌봄 · 기혼 · 자녀 1").
- **인생 지도**: 1칸=1년 격자, 색 농도 = 그 해 행복, 글자 마커(학/직/†), 테두리 칸 = 기대수명.
- **생존 곡선**: 같은 해 출생 코호트 생존 비율 라인(국가·성별 / 세계 평균).
- **국가 통계 카드**: 연간 출생아, 인구, 기대수명 여/남, 5세 미만 사망률, GDP(PPP), 지니, 도시 거주, 농업 종사, 기대 교육연수, 고등교육 취학률, 인터넷 이용률, 합계출산율, 모성사망비, HIV 유병률, 살인율, 교통사고 사망, 담배 사용 남/여, 의료비 본인부담, 18세 전 결혼(여성), 삶의 만족도 + 출처 문단.

### 3.2 시간 흐름
- `S.t`(0~1, 한 해 안의 진행률), `S.age`, `S.yearSec`(1시간 설정·탄자니아 65세 → 55.4초), `S.speed`(16), `S.paused`.
- 설정 "1시간 기준 1년이 40~60초" = `paceMin*60 / 기대수명`.
- 0~5세 "아기" 구간은 결정이 없어 8× 권장 문구가 뜬다.

### 3.3 결정 모달 3종(실측)

### 3.5 돈 모델(관찰)
- 소득은 국가 소득분포(지니 기반 로그정규 추정)에서 백분위 `pct`로 정해지고, 직업·경력(`exp{job:[years, …]}`)·공식/비공식(`formal`)에 따라 변한다.

- 지출 구조 %는 나라·소득에 따라 자동(식비 50%, 주거 25%…). 저축 2%.

## 9. 패러디 설계 시 가져갈 뼈대 (아이디어만)

1. **설정 3축**(세상/추첨 기준/길이) → 패러디 대상에 맞는 축으로 치환.
2. **출생 신고서 → 인생 화면 → 사망 기록** 3막 구조와 여권·MRZ·사망 기록 번호 같은 "공문서 코스프레" 톤.
3. **4스탯 + 돈 + 가족 패널**, **올해의 초점 칩**, **중대/작은/잠시 멈춤 3종 모달**(카운트다운 자동 선택 포함).
4. **이벤트 = {조건, 가중치, 본문, 각주, 선택지[효과 힌트]}** + 플래그/굴림/최근 목록으로 반복 제어. 각 줄의 "출처 각주"가 패러디에서 가장 비틀기 좋은 장치(가짜 논문·엉뚱한 통계).
5. **동행자 4명 사전 계산** — 병렬 시뮬 없이 요약 배열만 생성.
6. **엔딩**: 요약문 템플릿, 사인 + 3문장 비교, 16유형 "결", 훅 점수화 공유문, URL 코드 인코딩(서버 저장 불필요), 픽셀 컷 시네마틱.
7. **기술**: 프레임워크 없는 단일 HTML + 단일 JS, 전역 상태 1개, rAF 루프, localStorage 저장. 패러디도 이 규모로 충분(한국어 전용이면 i18n 레이어 제거).

## 10. 번들 코드 구조 맵

번들 정적 분석(줄 번호 인용 포함, 17개 절)은 별도 문서 **[원작_코드맵_80억분의1.md](원작_코드맵_80억분의1.md)** 참고. 핵심만:

- **번들 순서**: i18n(1–1069) → 데이터 테이블(1070–1590) → RNG·인구통계 수학(1591–1866) → 시뮬 코어·결정·이벤트(1867–16291) → ERA 시대 시스템(16292–17514) → 엔딩·카드·픽셀·추모관(17515–24916) → UI·영속성·부트스트랩(25184–28539).
- **시간**: `yearSec = clamp(paceMin×60 / max(기대수명, 60), 12, 120)`; `tick(dt)`가 `dt×speed/yearSec`만큼 `S.t`를 진행하며 큐를 소비, 결정이 열리면 시간 정지, `t≥1`이면 `endYear()`.
- **planYear**: 역사/경기 이벤트 → 초점 보정 → `scheduledDecisions()` 중 앞 2개만 큐 → 피드 이벤트 3개(6세 미만 2개, 가중 추첨·최근 14개 ×0.08) → 마일스톤(1·5·15·30·50·65·80·90·100세).
- **endYear 순서**: 초점 효과 → 취미 → 학교 → `finances()` → 건강/관계/행복 목표값 수렴(비대칭 수렴률) → 60여 개 `*Year()` 서브시스템 → 장부 마감·`years.push` → 사망 판정(`deathParts` Gompertz-Makeham 생명표 × 개인 승수 → `pickCause` 가중표 + 자살 share 합성 → 말기/암 생존 분기) → `age++` → `planYear()` → 저장.
- **결정 스키마**: `DEC[id] = { ok?(p), build(p) → {title, body, fact, choices[{k,label,sub}], input?, ph?}, apply(k, p, text) → 로그 }`; `SAME_WAY`로 이전 선택 기억·자동 재적용; 카운트다운은 자동 결정 모드에서만(본문 길이/9초, 5~14초).
- **이벤트 스키마**: `{ id, a:[min,max], c?(), w?, gap?, rep?, run() → string | {t, k, f} }`.
- **돈**: 지니 → 로그정규 σ, `incomeAt(c, pct) = ppp×0.9×exp(σΦ⁻¹(pct) − σ²/2)`; 중위소득이 모든 비용의 단위; PPP$1 = 850원 고정 환산; 백분위 drift(경력 10년 0.015/년, 초점 가산, 55세+ 감소).
- **HOOK 인터페이스**(`log/change/decision/death/year/err/noPause/calm`)로 엔진과 UI가 분리되어 있어, 동행자 시뮬·교육용 Web Worker 실험실이 같은 엔진을 재사용한다. 패러디도 이 분리를 처음부터 가져가는 게 좋다.
- **패러디에서 통째로 뺄 수 있는 것**: i18n 보정기, ERA(지난/다가올 세상), 간직하기/추모관/전생의 집, 실험실, 서버 백업/기록 옮기기, 분석 비콘.
