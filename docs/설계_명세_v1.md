### 3.2 소속 — `data/affiliations.json`

```jsonc
{ "id": "SIR_BELLONE", "track": "SIR_FAMIGLIA", "name": "벨로네 패밀리", "canon": true, "weight": 0.25,
  "mods": { "promo": 1.0, "fall": 0.8, "income": 1.3, "standingStart": +10 }, "tags": ["major"], "events": "SIR_FAMIGLIA:bellone" }
```
진입 시 `weight`로 하나 배정. `mods`는 승급·몰락·소득 배율. `tags`는 단계 `requires`에 쓰임. 소속 변주 이벤트는 태그 `aff:<id>`로.

### 3.3 연간 처리 순서 (`trackYear(sim)`, `endYear` 안에서 `finances()` 앞)

1. **진로 없음**(학생·아동·실업·가사 전담): `entry` 후보 산출 → 매년 `seekP`(기본 0.6, 실업이면 0.9)로 진입 롤. 후보 가중 = `classes[q]` × gates weight × 관계 등급 배율(§9) × 역량 적합도(해당 진로 첫 단계 `promo.cap` z에 로지스틱). 후보가 여럿이면 **결정 모달**(`track_choose`, 선택지 2~4개, 국가 특수 진로가 있으면 최소 1개 포함 — D26). 자동 결정은 가중 롤.
2. **진로 있음**: `years += 1`. `minYears` 충족 시 승급 롤 `p = clamp(k × (1 + z(promo.cap)) × (0.5 + standing/100) × aff.promo, 0, 0.6)`; 성공 시 `stage+1`, 로그 `kind:'big'`, standing +10. 몰락 롤 `p = fall.base × aff.fall × (1 − 0.15·luck) × 분쟁·정책 배율`; 발동 시 `causes` 가중 롤 → `exits.fall[cause]` 적용(§3.5). `standing`은 매년 ±(초점 `work`/`ties` 효과, 이벤트 fx).
3. **역량 성장**: 진로 단계가 보는 `promo.cap`이 연 +0.04z(최대 단계×0.6까지), 초점(§6.2)이 +0.02~0.05z. 학식은 학교 재학 중 +0.08z.
4. **소득**: `income.stage[stage] × 중위소득 × aff.income × (1 + 0.1·z(skill))`. 생업 진로는 `jobs.json`의 lo/hi 백분위를 쓰되 drift 없음.
5. **은퇴·전직**: `exits.retire.age`(종족 lifeMul 보정) 또는 건강<40이면 은퇴 결정. `switch` 후보는 결정 `track_switch`(연 1회 이하, 이벤트가 열 때만).

### 3.4 `job` 과의 관계
`S.job`은 표시용 문자열 소스로만 남긴다: `trackName(stage)` → 신원 카드 "직업"란과 사망 요약. 생업 진로의 `job` 필드는 기존 `jobs.json` id를 가리켜 소득 범위를 빌린다.

### 3.5 몰락 결과 `exits.fall` 값 사전
`death`(사인 = cause 매핑, §11.4) · `prison:jail|camp` · `exile`(§7 추방 이주) · `demote`(stage −1) · `expel`(진로 이탈, 실업) · `injured`(건강 −30, 진로 이탈) · `infected`(감염 발생 후 진로 이탈) · `disgrace`(standing 0, 다음 진로 가중 ×0.3) · `arena`(카시미어 감염자 혈투 리그 등 하위 진로로 강제 전환 `to:`).

## 5. 진입 가중의 기본 공식(창작)

`w = classes[q] × Π gates.weight × relMul(rel) × fit × nationSpecialBoost`
- `relMul`: 우대 1.3 / 무관 1.0 / 은근 0.8 / 문화적 0.6 / 제도적 0.2 / 배제 0.
- `fit = logistic(z(promo.cap of stage0) − 0.3)`(0.2~1.0).
- `nationSpecialBoost`: 국가 특수 진로(`canon:true && archetype≠A10/A11`)는 ×1.2, 단 **결정 후보에 최소 1개 노출**(D26)하되 선택 확률은 가중대로.
- 결과 분포가 카탈로그의 "계층별 유입" 비율에 ±10%p로 맞는지 `test/sim.js` 집계로 확인(W11 밸런스).

## 6. 역량·타고남 규칙

### 6.1 출생 롤
- `cap.*` 초기값: 전부 N(0, 0.6) + 분위 보정(learn: (q−3)×0.25, ties: (q−3)×0.35) + 종족 보정(`races.json` `artsApt`→arts, 새 필드 `skillApt`→skill) + 기질 보정(끈기 skill+0.1, 호기심 learn+0.1, 다정함 ties+0.1, 활발함 skill+0.1).
- `born.looks` N(0,1) 고정. `born.luck` N(0,1) 숨김. 극단(|looks|>1.5)이면 신원 카드 특성 줄.
- 기존 `tal`(재능 6종)은 유지하되 콘텐츠 문구용으로만.

### 6.2 성장
- 초점(FOCUS) 효과 재매핑: 공부→learn +0.05z, 운동→skill +0.04z, 아츠 수련→arts +0.04z(감염자는 진행 가속 유지), 가족·친구→ties +0.03z, 일에 몰두→standing +4 & skill +0.02z, 자기계발→learn +0.03z, 쉼·균형→건강·행복만.
- 진로 재직 연 +0.04z(해당 cap), 상한 = 단계수×0.6 + 1.0.
- `ties`는 이주 시 −60%(§7), 투옥·추방 시 −80%, 외모 |looks|>1에서 연 ±0.01.
- 쇠퇴: 60세+ skill −0.02z/년(lifeMul 보정), 치매 플래그 시 learn 감소.

### 6.3 외모 변경(D46)
결정 `looks_change`(성인, 돈 ≥ 중위소득 3배, 연 1회 이하 노출, 라이타니엔·컬럼비아·용문·극동 남조에서만 열림): 아츠 시술/수술 → 성공 70% looks +1.0, 실패 20% 건강 −15, 사고 10% 건강 −40. 서사는 담백하게.

### 6.4 표시
UI는 z를 숨기고 4등급 라벨. 소속 지위는 `track.standing`을 그 진로의 `standing.name`으로 0~100 바.

### 10.2 신분·부서
`status`: `operator`(정식 직원) / `contractor` / `patient`. 배치 규칙: 감염+치료 목적 → patient(치료비 노동 대체면 `dept: logistics`), skill 높음 & 비감염 또는 경증 → operator(외근부), learn 높음 → medical/engineer, 그 외 → logistics/purchase/office. 로도스 내부 진로 `RHO_*`(카탈로그 §22)는 §3 스키마로 `data/tracks/rhodes.json`.

### 10.3 이스터에그(D42)
- `status=operator && dept=field`이면 신원 카드에 캐논 6종 등급(결함/보통/표준/우수/뛰어남/탁월): 물리적 강도←0.6·skill+0.4·(건강 z) / 전장 기동력←0.5·skill+0.3·(기질 활발)+0.2·건강 / 생체 인내도←건강 z − 감염 단계×0.5 / 전술 계획력←learn / 전투 기술력←skill + 복무·용병 경력 0.3 / 오리지늄 아츠 적응성←arts. z→등급: <−1 결함, <−0.3 보통, <0.4 표준, <1.0 우수, <1.7 뛰어남, 이상 탁월.
- `status=patient` 또는 감염자 직원: "임상 진단 분석" 블록 — "[체세포와 오리지늄 융합률] n%" = `clamp(uL × 28 + N(0,1.5), 0, 60)`(창작), "[혈중 오리지늄 결정 밀도] n u/L" = uL, 그 뒤 한 문장은 캐논 프로필 톤의 템플릿 6종에서 단계별 선택.

### 10.4 열리지 않는 경우
`data/rhodes.json.closed`: 우르수스 수용소 수감 중, 라테라노 비감염 산크타(추방 전), 카즈델 군사위원회 소속(1094~98), 에기르 해저 거주, 두린 지하, 극동 북조 농노(접점 없음) → 소문 이벤트만.

### 2. ctx API (콘텐츠 콜백 첫 인자 `ctx` = sim)

getter: `ctx.track`(정규화 진로 또는 null) · `ctx.stage`(현재 단계 객체) · `ctx.aff`(소속 또는 null) · `ctx.res`(`S.res`) · `ctx.rel`(관계 등급 문자열) · `ctx.rhodes`(`S.rhodes` 객체 또는 null) · `ctx.job`(jobs.json 항목 또는 **진로 기반 가짜 job** `{id, name, oriMul, special, track, stage, …}` — 구 콘텐츠 호환) · `ctx.policy`(진로 `oriPolicyOverride` 우선).

헬퍼(전부 ctx 메서드):
- `ctx.promote({force?, quiet?})` → bool. 승급(상한·requires 검사, force 면 무시).
- `ctx.fall(cause?)` → 결과 종류. cause 생략 시 단계 causes 에서 뽑아 `exits.fall` 적용. `ctx.applyExit(value, cause)` 로 값 사전 직접 적용.
- `ctx.switchTrack(id, how?)`, `ctx.enterTrack(id, {via, how, aff, stage, quiet, skipExam, reason})`, `ctx.leaveTrack(how, {quiet})`, `ctx.retireTrack({full})`. **타국 진로로 enterTrack/switchTrack 하면 그 나라로 이주가 먼저 일어난다**(reason 기본 work, forcedEntry 면 exile).
- `ctx.migrate(reason, to?, {papers, keepTrack, quiet})` — reason: `work|study|marriage|flee|asylum|exile|contract|caravan|rhodes|return|deport`(구 `expel|insurance_default|voluntary` 도 받음). `to` 생략 시 §7.1 후보 가중 롤. 도착 papers 는 `papersFor()`.
- `ctx.joinRhodes(via, {place, quiet})` — via 9종. 배치는 `rhodes.json statusRules` 첫 일치.
- `ctx.setHousing(typeId, {buy, quiet})`, `ctx.infect(how)`, `ctx.eff({hl,h,money,cap:{skill:+0.1},standing:+5, sm, so})`(sm/so 는 1점 = 0.01z 로 learn/ties).
- 플래그로 여는 내장 결정: `S.flags.switchOpen = true` → `track_switch`; `S.flags.omen = true` → A7 승급 롤 정상 배율; 로도스 접점은 `S.flags.rhodes_operation|rhodes_legal|rhodes_medical_pact|rhodes_rescue = S.age`(그 해·다음 해 유효, referral), `S.flags.bigevent_survive|fall_experiment_survive|fall_camp_survive = S.age`(rescue, `catastrophe_hit` 은 엔진), `S.flags.rhodesCompanion = true`(companion). `S.flags.lastFall / lastFallAt / lastFallOutcome` 은 마지막 몰락.
- 내장 결정 id(콘텐츠가 같은 id 를 등록하면 **그쪽이 우선**): `track_choose`, `track_switch`, `contract_end`, `looks_change`, `migrate_work`, `migrate_study`, `naturalize`, `return_home`, `marry_<type id>`(marriage.json 유형마다 복제), `marry_second`, `home_change`, `rhodes_offer`. 문구는 전부 임시(담백체) — W9 가 덮어쓴다. 선택지 `k` 는 유지할 것(`track_choose`: 진로 id / `wait`, `marry_*`: accept/hold/decline, `rhodes_offer`: join/hold/decline, `home_change`: 유형 id / no, `naturalize`: yes/no, `return_home`: go/stay, `contract_end`: re/leave).
- UI 용 export(`sim.js`): `grade(z)`, `capProfile(S)`, `trackName(sim)`, `rhodesCard(sim)`(`operatorProfile`·`clinical` 포함), `migrationSummary(S, data)`, `migrateSave(S, data)`, `healStats(S)`, `sim.load(S)`.

### 4. 명세와 달라진 점

1. **`S.born` 은 출생 국가 id 그대로, 타고남은 `S.innate = {looks, luck, trait}`** (§2 의 `born` 이름 충돌). `innate.trait` 은 childhood 결정이 세우는 `S.trait`(cur/act/warm/grit)를 그대로 비춘다.
2. **`S.home.type` 은 `nomadic|settled` 를 유지**(광석병 배율·구 콘텐츠·death_texts 가 읽음). §8.2 주거 유형은 `S.home.housing`(+`since`, `owned`, `forced`). 주거비(`cost`)는 아직 가계에 안 물린다(소유형 `buy/price` 만 돈이 나간다) — W11 밸런스.
3. **진로 진입은 연말이 아니라 planYear 의 내장 결정 `track_choose`** 가 한다(ok 에서 seekP 롤, 후보 1개면 모달 없이 즉시 진입, 2개 이상이면 2~4개 + 국가 특수 진로 1개 보장 + "한 해 더 본다"). 결혼도 `marry_<type>` 결정이 롤부터 맡는다(같은 해). 내장 결정은 레지스트리 앞쪽에 들어가며 우선순위는 `rhodes_offer > track_choose > contract_end > migrate_study > naturalize > return_home > migrate_work > marry_* > marry_second > track_switch > home_change > looks_change`.
4. **`S.st.sm/so` 삭제.** `statYear` 의 옛 '관계' 항은 `cap.ties` 기반 proxy 로 행복 목표식에 들어간다. 구 콘텐츠 fx 의 `sm/so` 는 `applyLegacyFx` 가 learn/ties z 로 흡수한다.
5. **`S.job`** = 진로의 `job` 필드(A11) 또는 **진로 id**. `jobs.json` 에 없는 id 라도 `ctx.job` 이 가짜 job 객체를 돌려주므로 `s.job.oriMul` 류 구 코드는 안 깨진다. 콘텐츠가 `S.job = null` 로 두면 다음 연말에 진로도 끝난다(`how:'content'`). `takeJob()` 은 진로 없이 구 직업을 주는 호환 경로(소득 백분위 고정, drift 없음).
6. **몰락 확률 전역 배율**: `balance.track.fallScale 0.45`(데이터 `fall.base` 에 곱함)와 `deathSoften 0.35`(death 결과는 35% 만 실제 사망, 나머지는 폭력·사고면 `injured`, 아니면 `expel`; forced 진로는 예외). 명세 §13 base 0.01~0.08 을 그대로 쓰면 평생 몰락 60%+, 평균 수명 −10년이 되어 넣었다. W11 이 calibrate 를 다시 돌리면(`data/terra_e0.json` 재생성) 다시 조정 가능.
7. **로도스 입구 확률 배율 `balance.rhodes.pScale 0.12`**(데이터 `p/pYear` 에 곱함). 그래도 합류율은 전체 약 6%, 감염자 중 25~30% 로 목표(1~3% / 8~15%)보다 높다 — 원인은 구 콘텐츠(`adult_infected.js`·`childhood.js`·`elder.js`)가 직접 `S.rhodes = true` 로 합류시키는 경로(연 45% 등). 엔진은 `S.rhodes === true` 를 다음 planYear/endYear 에 `treatment` 객체로 정규화한다. **W11 이 그 경로를 지우면 목표 안에 들어온다.** 구 '엽서' 자동 합류(oriYear 연 30%)는 폐기했고 `rhodesOfferP` 는 0.02.
8. **이주 경험률 약 23%**(목표 10~20%). 사유 상위: 귀향(return)·구 콘텐츠 `adult_migrate`(voluntary ≈ 8%)·work·exile(정책 추방+몰락)·flee. `balance.mig.*` 로 더 내릴 수 있으나 voluntary 는 콘텐츠 몫.
9. **A4 평민 상한**: 데이터 단계의 `capStage:{q1:true}` 가 "그 단계가 상한" 의미(W8). track 수준 `capStage:{q1:2}` 도 받는다. 귀족(`status.noble`)은 상한 없음. 작위는 출생 롤(q5 60%, q4 15%, 창작).
10. **A6 계약**: 단계 `contract:n` 이 있으면 그 연수, 없으면 원형 기본 [2,4] 롤. 만료 시 `contract_end` 결정(재계약/떠남). 승급하면 다음 단계 contract 로 갱신.
11. **A2 감염 → arena**: `exits.fall.infected = 'arena:<ID>'`(KAZ_KNIGHT). 진단 직후 `onDiagnosed()` 가 적용. A7 은 자진 사퇴, A6 은 `exits.fall.infected` 가 있으면 적용.
12. **forced 진로 진입**: 진단 시 정책 `persecute` 의 수용소 분기에서 거주국의 forced 진로(`forced.infected && policy 포함`)로 `enterTrack(how:'forced')`. 그 외 forced 진로(LEI_QUAR·VIC_INFECTED·COL_INSURANCE·LAT_FALLEN·RIM_INFECTED·KAZ_INFECTED)는 **콘텐츠가 `ctx.enterTrack(id, {how:'forced'})` 로 넣는다**(정책 분기 이벤트에서). `oriPolicyOverride: 'kaz_arena'` 같은 미지의 정책 id 는 `applyPolicy` 가 `ignore` 로 처리한다.
13. **이주 state**: `S.res.papers` 에 `native` 추가. 불법 체류 발각(연 `nation.illegalRisk`, 기본 0.08)은 출생국으로 강제 송환(`deport`). 난민→합법 연 15%. 귀화 결정은 10년+ 합법 거주에서 연 10%, 귀향 결정은 10년마다·부모 사망 시·유학 종료·계약 종료 시. 순회형 `itinerantAt` 은 `route` 가 없으면 `nation.mig` 키, 로도스 본함은 `rhodes.json ports` 가중. `lostYear`(1101)는 아직 반영 안 함.
14. **관계 매트릭스**: `relations.json` 의 `relMul` 이 있으면 그것을 쓴다. `ethPairs` 는 `pairs` 에 합쳐 `eth` 키로 본다. 소득 배율 institutional 0.7 / cultural 0.9, 분쟁 피해 확률 ×1.5/1.2, 결혼 반대는 종족 간 혼인에서 cultural 이하 40% 무산, 출생·이주 목적지에서 exclude 제외.
15. **혼인**: `dowry` 부호는 W8 규약(양수 = 신랑 쪽이 냄). 격리구역 거주자는 `req.infected:true`(= `infected_only`) 유형 강제. 타국 출신 배우자(5%)는 50% 로 `marriage` 이주. `poly` 둘째 배우자는 `marry_second`(소득 조건).
16. **주거**: `_common` 유형은 모든 국가에 붙는다. `forced` 키 `oriPolicy+known / prison / res / track / archetype+stageMin,stageMax / papers / flag`. `own+price` = 소유형(`buy`). A11 소유 단계에서 돈이 되면 자동 구매(5년 간격).
17. **진로 없는 국가**(실데이터 누락 시)에는 `GEN_<NATION>_LIVING/_FARM`(A11, `synthetic:true`)을 합성하므로 모두가 진로 상태 기계를 탄다. 더미 모드(`DATA=dummy`)는 시라쿠사·우르수스·컬럼비아만 진짜 더미 진로.
18. **구 콘텐츠와의 경계**(W11 정리 대상): 공통 직장 이벤트(`adult_work.js`)는 아직 전 원형에 열려 있다(`archetype:A10` 태그는 엔진이 제공, 콘텐츠 재태깅은 W11). `adult_nations.js` 의 `takeJob('knight')` 류는 진로 없는 구 직업으로 남는다. `S.mig`(마지막 이주국)·`S.flags.migReason` 은 호환용으로 유지.
19. **저장**: `S.v = 2`. `sim.load(S)` → `migrateSave`(sm/so→cap, job→가장 가까운 A11 진로, mig→res, home.housing 기본값, rhodes true→객체) 실패 시 null — UI 가 토스트 후 삭제.
20. **미구현(콘텐츠 몫으로 남김)**: A1 배신 결정(`_dummy_tracks.js` 에 예시), A2 스폰서 결정, A3 파벌(standing 하나로 통합), A9 자가 실험 결정, 상단 동행(`caravan`) 트리거, 캐논 인물 게이트(`data.canonFigures` 로드만), 로도스 본함 소실(1101.7), 주거비 과금. W8 gate `status` 중 `orphan` 은 엔진이 15세 전 양친 사망 시, `ninja_clan` 은 극동 상층 2% 출생 롤로 세운다.

### 5. 검증 명령과 현재 수치 (실데이터, N=1000, seed w2/w3)

`node test/validate-tracks.js` 오류 0 / `node test/sim.js 1000` 예외 0, 전체 가중 Δ −1.6 / −1.4, ±5 이탈 없음, 감염률 등급 단조. 로도스 6.0% / 감염자 중 26~32%(위 7), 이주 23%(위 8), 기혼 73%, 생애 중 진로 경험 80%, 승급 1600~1750회/1000명, 몰락 사망 50~75명/1000명. 국가별 계층 유입은 `[v1] 진로` 블록이 ±10%p 이탈을 찍는다(염국·컬럼비아 일부 이탈 — W11 밸런스).
