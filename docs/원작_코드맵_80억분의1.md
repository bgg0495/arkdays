## 2. 데이터 테이블

### 2.1 `COUNTRIES` (ko.js:1070) — 172개국, 한 줄 JSON 배열
필드(한국 행 예시 `{"id":"KOR","ko":"대한민국","p":"hi","nm":"ko","rel":"N52,C28,B19,O1","sp":"baseball,football","b":236394,"pop":51749,"le":84.3,"gap":6.1,"u5":2.9,"im":2.4,"ppp":54029,"gi":0.33,"tfr":0.72,"mmr":8,"urb":81,"agr":5,"hiv":0.03,"hom":0.5,"road":6.5,"mal":0,"net":97,"ter":100,"eys":16.6,"sm":35,"sf":6,"oop":30,"cm":0.5,"wh":6.06,"cs":[18,0,"u"],"war":0,"mig":"USA,CAN,AUS,JPN","haz":"S"}`):

| 키 | 뜻 |
|---|---|
| `id` ISO3, `ko` 한글명, `p` 지역(`hi/eca/eap/sa/ssa/mena/lac`), `nm` 이름 클러스터(→`NAMES`), `rel` 종교 비율 문자열 `"M100"`/`"N52,C28,B19,O1"` (C기독/M이슬람/H힌두/B불교/N무종교/O기타/F민속/S시크…), `sp` 인기 스포츠 |
| `b` 연간 출생아(절대수), `pop` 인구(천 명) — 출생가중/인구가중 추첨의 가중치 |
| `le` 기대수명, `gap` 남녀차, `u5` 5세미만사망률(‰), `im` 영아사망률(‰), `mmr` 모성사망비 |
| `ppp` 1인당 GDP(PPP$), `gi` 지니계수, `tfr` 합계출산율, `urb` 도시화%, `agr` 농업종사% |
| `hiv` 유병률%, `hom` 살인율, `road` 교통사고사망, `mal` 말라리아 지수, `net` 인터넷%, `ter` 고등교육 취학률, `eys` 기대교육연수, `sm/sf` 남/여 흡연율, `oop` 의료비 본인부담%, `cm` 18세전 결혼(여)%, `wh` 삶의 만족도(0–10) |

### 2.2 `NAMES` (1076–1341) — 약 90개 문화 클러스터
키: `hi ur bn zh ja ko vi th my kh lo fil id ms mn ne si ps fa ar so tr ca ru ua ka en zhd de fr it es pt nl nd pl cz hu ro bg sr el he la br ht ngn ngs sw am cf wf gh za zaf lu mg rw ss pg sik ug bo mmm inm inc bh pkc lkm ta amm swm arc wfc tdc idc ba film bsm hk hr hy lt sq sl lv mk tl et sz fj km dv sb mt`.
각 항목 `{ o, m[], f[], s[], x?[], fs?, fem?, m1..m4/f1..f4?, mm/fm? }`: `o`는 조합 순서(`'gf'` 이름+성, `'fg'` 성+이름, `'fgns'` 붙여쓰기(한중일), `'pat'` 부칭, `'bin'` bin/binti, `'vi'` 베트남식 중간이름, `'mono'` 단명). `x`는 달리트 성, `m1~m4`는 출생연도 밴드별 이름(`nameBand` 2724). `makeName(cl, sex, o)`(2725)가 `{g, base, full, cl}` 반환. 예: `hi: { o:'gf', m:['Aarav','Rahul',…], f:['Priya',…], s:['Sharma','Kumar',…], x:['Ram','Bharti',…] }`.

## 7. 이벤트 시스템

세 층위가 있다: (a) **피드 이벤트 `EVENTS`** (무작위, 선택 없음), (b) **결정 `DEC`** (모달, 선택지), (c) **역사 이벤트** (`HIST`/`ERA_*`, 시대 모드). 그 외 `SMALL`(작은 선택, 18207), `HUM`(사람 이야기, 18168), `WARM`(따뜻한 순간, 18036)은 `scheduledDecisions` 안에서 `smallPick/humanPick`(18291/18303)으로 결정 풀에 섞인다.

## 9. 죽음

### 9.1 생명표 `lifeTable(c, sex)` (1715–1738)
입력 `le, gap, im, u5, R514`. `e0 = sex F ? le+gap*.49 : le-gap*.51`. `q0=im/1000*k`(k F.92/M1.08), 1~4세는 `u5` 잔여를 `[0.4,0.27,0.19,0.14]` 가중 분배, 5~14세 `q514`, 15세+는 **Gompertz-Makeham** `A + B·exp(g·x)`(g=0.085~0.112)의 B를 이분법 50회로 e0에 맞춤. `OLDEST`(1713) 초고령 하한. 반환 `{q[0..110], l[0..111](생존곡선), e0}`. 캐시 `LT_CACHE`. 시대는 `survL/cohortL`(16596/16603 코호트 생존).

## 16. i18n — `L` 태그 함수 (65–91)
- 모든 UI 문자열은 ``L`한국어 원문 ${값}` ``. `L0(strs, vals)`: **`LANG==='ko'` 이거나 `I18N_T`가 없으면 그냥 `lJoin`(원문 조립)** → 한국어 전용 패러디는 `L`을 `(s,...v)=>lJoin(s,v)`로 바꾸거나 그대로 두면 됨(이 번들은 `window.LANG='ko'` 하드코딩, 1행).
- 다국어: `strs.join('\u0001')`을 `lHash`(65, cyrb53 변형 → base36)로 해시 → 외부 사전 `I18N_T[hash] = "번역 {0} {1}"` 조회(`L_CACHE` WeakMap, 미번역은 `L_MISS`). 언어별 후처리 `frFill/thFill/esFill/deFill`(문법 성·수 처리), `{@key}` 상담전화 치환, `enFix` 단수화, `cjkFix`.
- 디버그 링 `L_RT/L_RS`(73) 최근 8개 호출. `capS`(110) 문장 첫 글자 대문자화(ko/th 제외). 한국어 조사 처리 `eul/iga/ro/eun/ira/wa`(1643–1699, 받침 검사 `hasB` 1635 — 한글/숫자/영문 끝 처리).
- 번들 2~1069행(언어 설정·HELP 테이블·서양어 문법기)과 각 함수의 `LANG === 'en' ? … :` 분기는 한국어 전용이면 모두 제거 가능. 통화는 `KRW=850`과 `wonStr` 한국어 분기(1859–1862)만 유지.
