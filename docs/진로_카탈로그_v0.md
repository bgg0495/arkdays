# 진로 카탈로그 v0 (검토용)

작성 2026-10-20 · 상태: 사용자 빨간펜 대기. 근거는 `docs/진로_소속_초안.md`(196KB)와 `research_notes/테라 국가별 진로 소속 목록/`. 규칙은 `docs/결정사항.md` D39·D40.

**읽는 법**: 국가마다 (1) 평범한 사람의 기본 생애 한 줄 → (2) 진로 표 8열 → (3) 계층별 유입 비율(전부 창작 제안) → (4) 감염 시 분기 → (5) 빠진 것. 1부 = 염국~컬럼비아 11개국 141진로, 2부 = 시라쿠사~두린 10개국 116진로, §22 로도스 아일랜드 별도 루트(입사 경위 9유형 → 입구 조건, 신분 3종, 내부 진로 9개), 공통 고용주 10진로. **합계 약 276진로.**

**검토 요청**: 진로 추가/삭제/병합, 단계 명칭, 잘 풀림·평범·몰락이 그 나라답냐, 계층별 유입 비율의 감, 로도스 입구가 "지원서"가 아닌 서사로 충분한가. 수치·능력치는 이 단계에서 정하지 않음(능력치는 카탈로그 확정 후, 소속별 차이 가능성 포함해 별도 논의).

## 범례

- **A1 패밀리/범죄조직형** — 심부름→솔다토→카포→언더보스→돈. 상한에 합법화 출구.
- **A2 기사 스포츠형** — 등록→연습생→정예→MVP→대기사→은퇴. 신체+스폰서.
- **A3 관료·과거형** — 수재→시험→하급 관원→중급→상서·재상. 학식 입구, 정치 몰락.
- **A4 군단·징집형** — 병→하사관→장교→장군. 평민 상한은 하사관~대위.
- **A5 광산 노역형** — 강제(감염)·자발(무교육)→종치기→광부→감독(드묾). 사망이 기본 몰락.
- **A6 용병형** — 연습생→오퍼레이터→정예·교관→임원·창업. 전사·감염 해지.
- **A7 부족·사제형** — 부족민→전사/사냥꾼→샤먼 견습→샤먼→사제. 성공이 곧 침식 위험.
- **A8 교단·수도원형** — 입문→수행승·수도사→정식→장로. 좌천·독살·하산.
- **A9 연구·기업형** — 대학→인턴→연구원→디렉터. 자가 실험·실종, 해고 없음.
- **A10 회사원형** — 입사→사원→매니저→임원. 과로·파산·감염 시 추락. **A11 생업형** — 가족 노동→견습→자영→촌장·도매상. **A12 예인형** — 오디션·거리→전속·후원→악장·스타.
- **표 읽는 법**: `id`는 `국가코드_이름`. 단계 사다리는 캐논 명칭 우선, (창작) 단계는 괄호. "잘 풀림/평범/몰락"은 결말 세 갈래의 대표 상태. 소속 변주는 같은 진로 안에서 이벤트 풀·결말 확률이 갈리는 집단. 유입 비율은 전부 창작 제안값.

### 22. 로도스 아일랜드 — 별도 루트

출생 국가가 아니라 **어떤 생애든 들어올 수 있는 루트**. 설정상 "배경·경력·상태 불문"으로 가치를 공유하는 사람을 받고, 치료비 못 내는 환자는 고용·자원봉사로 대체하며, 외부 세력과는 협정·각서로 묶는다. **"공개모집"·"헤드헌팅"은 게임 UI 용어(公开招募·寻访)이므로 서사 텍스트에서 "지원서를 냈다"식 채용 공고 서사는 쓰지 않는다.** 서사는 인사부 채용과·심사과의 배경조사(사회관계·행동 분석)·입사 교육·정기 심리평가·감염 모니터 팔찌·ID 카드 3종으로만 표현한다. 규모: 본함 약 2,000명 오퍼레이터 + 1,000명 이상 환자. 비감염자 비율은 수치 없음(영문 "거의 전원 감염자" vs 나무 "비감염자 다수" 상충).
