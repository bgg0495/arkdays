## 1. 범위

**MVP에 넣는 것**
- 설정 1개(바로 태어나기) + 출생 신고서 + 인생 화면 + 사망 기록 + 공유 텍스트 복사
- 국가 21곳(하위 지역 포함) · 종족 약 20종 · 직업 30~40종 · 사인 25~30종
- 스탯 4종(건강·행복·지식·관계) + 돈 + 광석병 수치(u/L) + 아츠 적성
- 올해의 초점, 결정 모달 3종(중대·작은·잠시 멈춤), 자동 결정, 배속, localStorage 이어하기
- 공통 이벤트 약 60개 + 결정 약 40개 + 국가 태그 이벤트 약 60개(국가당 2~4개)로 시작

**MVP에서 빼는 것**: 동행자 4명, 픽셀 아트, 음악, 커뮤니티·추모관·결제, 시대 선택, 다국어, 기록 옮기기, 전생의 집. 동행자·픽셀 아트는 2차 목표.

## 2. 플레이 흐름과 시간 모델

```
[시작 화면] ─태어나기─▶ [출생 신고서] ─삶을 시작하기─▶ [인생 화면] ─사망─▶ [사망 기록]
 비중표·간단 설명         국가/지역·종족·성별·분위·      연 단위 진행            요약문·사인·통계 비교
 (설정 없음, 바로)        도시/농촌·부모·종교·감염 여부   초점/결정/이벤트         결·공유·다시 태어나기
```

- **출생 연도**: 테라력 1080~1100 균등 랜덤(D12). 화면에는 "테라력 1093년 봄" 식으로 표기.
- **길이**: 기대수명까지 **약 12분** 기준. `yearSec = clamp(720 / e0, 6, 14)`. 배속 1/2/4/8×, 기본 2×. "다음 결정까지" 버튼 유지.
- **루프**: `requestAnimationFrame` → `tick(dt)` → `S.t += dt*speed/yearSec` → 큐 소비 → `t≥1`이면 `endYear()`. 결정 모달이 열리면 시간 정지. 탭이 숨겨지면 멈추는 건 허용.
- **잠시 멈춤**: 5·15·30·50·70세. 질문 + 한 줄 입력(선택).

### 3.5 이벤트·결정 (`content/`)

원작 스키마를 그대로 따른다(구조만, 문구는 새로).

```js
// (D23) 전역 S 없음. 모든 콜백은 ctx(sim)를 첫 인자로 받는다. 태그 목록·'!' 부정은 src/engine/README.md
// 피드 이벤트
{ id, a:[min,max], tags:['yan','infected','miner'],  // 태그가 없으면 공통
  c:(ctx)=>bool, w:number|(ctx)=>number, gap:years, rep:bool,
  run:(ctx)=>string | {t, k:'ev'|'bad'|'big'|'warm'|'loss'|'note', f:출처각주, fx:{hl,h,sm,so,money}} }
// 결정 — ok(ctx)를 매년 평가해 게이트. once(기본 true), gap, at(연내 시각), 선택지 auto(자동 결정 가중치)
{ id, tags, once:true, ok:(ctx,p)=>bool,
  build:(ctx,p)=>{title, body, fact, choices:[{k,label,sub,auto}], input?, ph?},
  apply:(ctx,k,p,text)=>string|{t,k,f} }
// 캐논 대사건 (연도+나이 게이트)
{ id:'chernobog', nation:'ursus', year:1096, month:12, a:[0,120], once:true, run:(ctx)=>… }
```
실제 데이터 파일 형식(`{_meta, <key>:[…]}` 래퍼, 단위)은 W1이 만든 `data/README.md`가 기준이고, 엔진 `prepareData()`가 정규화한다. 이 문서 §3 표는 개념 설명으로만 본다.

- **각주(f)는 패러디의 핵심 장치**. 실제 통계 출처 대신 테라식 출처: "(로도스 아일랜드 의료부 연보, 1098)", "(용문 근위국 치안 백서)", "(컬럼비아 보험협회 추정)", "(출처: 본 시뮬레이션이 지어냄)". 담백한 서술 + 가짜 출처가 톤이다. 대놓고 개그 문장은 10%를 넘기지 않는다.
- 무거운 주제(광석병 판정, 안락사, 자살, 수용소)는 원작처럼 장면을 그리지 않고 결과만 서술한다.

## 4. 상태 객체 `S` (원작 필드 + 테라 확장)

원작과 같은 뼈대: `phase, t, age, speed, paused, by(출생연도), born, cur, sex, q(1~5), urban, city, name, st{hl,h,sm,so}, money, income, pct, job, edu, focus, fam{…}, log[], years[], queue[], pending, recent[], flags{}, done{}, deathAt`.

테라 확장:
| 필드 | 설명 |
|---|---|
| `race` | 종족 id |
| `eth` | 소수민족 플래그(`gaul`, `nomad`(타라 유목민), `outsider`(라테라노 비산크타) 등) |
| `arts` | 아츠 적성 z값(출생 시 종족 가중 롤, 고정) |
| `ori` | `{on:false, uL:0, since:null, known:false, treated:false}` — 감염 상태. `known`은 진단 여부 |
| `home` | `{type:'nomadic'|'settled', deck:'upper'|'under'}` 거주 형태 |
| `served` | 복무 기록, `prison` 수용소/투옥 |
| `rhodes` | 로도스 합류 여부 |

## 5. 핵심 규칙(초기값, 전부 추정)

### 5.1 광석병
- **출생 감염**: 부모 중 감염자 있으면 60%, 둘 다면 90%.
- **연간 감염 확률** `p = base[oriExp] × job.oriMul × home × race.oriVuln`, `base = {1: 0.2%, 2: 0.6%, 3: 1.5%}`, home: 정주 농촌 1.5 / 이동도시 지하 2.0 / 상층 0.7 / 황야 직업 추가 배율.
- **진행**: 감염 시 `uL` 0.05~0.20에서 시작, 연 +0.03~0.08. 치료(`treat` 국가, 로도스 합류, 돈으로 억제제) ×0.5. 아츠 과용 ×1.3. 재앙 피폭 시 +0.1.
- **단계**: <0.30 1기(미열, 들킬 확률 낮음) / 0.30~0.50 2기(결정 노출 → `known` 거의 확정, 건강 −, 노동 제한) / >0.50 3기(건강 −−, 직업 상실) / ≥0.80 사망 판정.
- **진단 이벤트**(`known`이 되는 순간)가 국가 `policy`로 분기: persecute→수용소·추방·처형 위험 / quarantine→격리구역 이주·이동 제한 / euthanasia→격리 + 3기 도달 시 국가 안락사 통지 / neglect→보호비·소모품 / insurance→보험료 청구, 미납 시 추방 / expel→즉시 추방(타국 이주 롤) / ignore→일상 유지 / treat→치료 접근. 모든 분기에 "로도스 합류 제안" 작은 확률.
- 감염자는 아츠 유닛 없이 아츠 사용 가능(소득·전투 보너스)하지만 진행 가속.

### 5.2 재앙
- 연간 `p = {1: 1%, 2: 3%, 3: 6%}[catFreq] × (nomadic 거주 0.3 / 정주 1.5)`.
- 결과 롤: 대피 성공(재산 −10%) 60% / 피해(재산 −40%, 건강 −) 30% / 감염(5.1 +0.1 uL 또는 신규 감염) 8% / 사망 2%. 재앙 정보 전달자 오보 플래그가 있으면 악화.
- 캐논 대재앙(체르노보그 1096.12, 쉐라그 1101.12)은 대사건 이벤트로 별도.

### 5.3 종족·차별
- 출생 시 국가 `races` 가중 롤 → 그 종족의 `home`에 현재 국가가 없으면 `eth:'outsider'`.
- `stigma` + 국가별 보정(라테라노의 살카즈 = 입국 불가, 이베리아의 에기르 = 박해)이 취업 제안 수·소득 백분위·결혼 후보·범죄 피해 확률에 곱해진다.
- 살카즈는 런디니움 사태(1098) 이후 빅토리아에서 전범 취급 이벤트.

### 5.4 징병·분쟁
- `conscript`: draft → 18세 복무 결정(국가 전쟁 플래그면 강제), mandatory → 3년 자동, volunteer → 직업 선택지, none → 없음.
- `conflict` 3인 국가는 연간 분쟁 피해 롤(재산·건강·사망), 전시 플래그면 ×3.

### 5.5 돈
- 소득은 원작 방식(지니 → 로그정규, 백분위 drift). 표시 단위 **용문폐(LMD)**: `LMD = PPP$ × 10`(창작 환율) + "용문 물가 체감" 문구.
- 감염 정책이 insurance면 연 소득의 15~30%가 보험료로 빠진다.

### 5.6 아츠
- 출생 시 `arts = N(race.artsApt, 1)`. 상위 10%면 캐스터 루트 결정(라이타니엔은 귀족 진입, 다른 곳은 용병·연구직). 아츠 폭주 사인 가중.

## W1 메모 (데이터 세션, 2026-10-19)

`data/*.json`을 만들며 명세와 어긋나거나 명세가 정하지 않은 점. 명세 본문은 고치지 않았다. 결정이 필요하면 `docs/결정사항.md`에 D번호로 올릴 것.

1. **§3.1 `policy` enum 하나로 못 적는 국가 4곳** — 용문(1098 이후 완화), 극동(남 insurance / 북 quarantine), 시라쿠사(도시 ignore / 시골 neglect), 사르곤(아미르별). `policy`에 기본값을 두고 `policyVariants: [{when, policy, note}]`를 추가했다. `when`은 엔진이 해석할 조건 문자열(`year>=1098`, `region=='north'`, `urban==false`, `amir=='mining'`)이라 W2가 파서를 정해야 한다. 극동은 `region`, 사르곤은 `amir` 출생 분기가 S에 필요하다(§4에 없음).
2. **§3.1 share 합 = 99.8** — D9 확정표 그대로 옮기면 100이 아니다(로도스 0.05 제외, 반올림). 검증기는 ±0.5 허용. 엔진은 가중 롤 전에 정규화하면 된다.
3. **§3.1 `(custom)` 국가의 통계 위치** — `model: []` + `custom: "KAZDEL"|"DURIN"` 키로 `stats1950.custom`을 가리킨다. 카즈델은 기준치(세계 평균 le 46)에 `statMul.le 0.8`을 곱해 약 37, 그 위에 살카즈 `lifeMul 2.5`가 곱힌다. 두 배율이 겹치니 §5의 수명 계산 순서(국가 → 종족)를 명세에 적어 두면 좋겠다.
4. **§3.2 종족 수** — 후보 24종 + 용·드라코(rare) = 26항목. `oriVuln`은 명세 글("살카즈 2.0(진행 1.5)")대로 `{infect, progress}` 객체로 했다. 표에는 숫자 하나처럼 적혀 있다.
5. **§3.3 직업 수 초과** — 공통 37 + 특수 58 = 95종. §1 MVP는 30~40종. 명세에 나열된 특수 직업만 넣어도 44종이 넘어서 불가피했다. 엔진이 한 생에 제안하는 직업 수를 제한하면 체감 수는 줄어든다. 스키마에 `age`, `req`, `special` 필드를 추가했다(피트싱커 아동 연령, 캐스터 적성 조건 등을 적을 자리가 없었다).
6. **§3.4 사인 수** — 33종(현실 11 + 테라 22). 명세 25~30종보다 많다. `tags`에 `threat:<key>` 형식을 추가해 국가 `threats` 키와 직접 연결했다. `kind`, `fact`, `footnote` 필드 추가.
7. **카즈델 출생 감염** — §5.1 출생 감염은 부모 감염 여부로만 정한다. 카즈델은 "대다수 감염"이므로 부모 감염 확률 자체를 국가별로 두는 필드(예: `parentInfectedP`)가 필요하다. 데이터에는 아직 없음.
8. **1950 통계 공백** — 홍콩은 OWID/UN 공개 CSV에 1950 행이 없어 `u5, imr, ppp, urb, tfr`를 추정(1951~1955 값에서 역추정). 지니는 24개국 전부 추정. 중국·러시아·이란·사우디 영아사망률은 U5MR×0.70 근사. 전부 `estimated:true`.
9. **기대수명이 짧은 모델** — 사르곤 모델(이란·이라크·사우디 1950) 기대수명 37~40년, 염국(중국) 43.8년. 비중 22%인 염국의 e0가 46 안팎이라 평균 플레이 길이가 §2의 12분보다 짧게 나온다. `statMul.le`로 보정하거나 `yearSec` 공식을 재검토할 것.
10. **이름 스키마 확장** — `o` 네 가지 외에 `raceRule`(오니 성 없음), `pat`(우르수스 부칭 표), `femSurname`(러시아·폴란드 여성형 성), `noble`(라이타니엔 '폰'), `doubleSurname`(이베리아·볼리바르 두 성)을 추가했다. 가울 유민용 `fr` 풀은 국가가 아니라 `ethnicFlags.gaul`에서 참조.
11. **아나티 home** — 보고서 A-5는 사미·쉐라그, 명세 §3.1 사르곤 표도 아나티를 적어 둘 다 home에 넣었다. 어느 쪽이 맞는지 확인 필요(사르곤 쪽은 아마 아나사/피디아 혼동).
12. **다른 세션 산출물** — 작업 중 `data/_dummy/`와 `test/sim.js`가 W2 세션에 의해 생겼다. W1 검증기는 `data/*.json` 6개만 본다.

## W2 메모 (엔진 세션, 2026-10-19)

`src/engine/*` 구현 중 명세와 어긋나거나 빠져 있던 것. 결정이 필요한 항목은 **[결정]** 표시.

### 데이터 스키마(§3) — W1 실제 파일 기준으로 엔진을 맞춤
- `data/*.json` 은 `{ _meta, <key>: [...] }` 래퍼이고 단위가 명세 표와 다르다: `u5`·`imr` 0~1, `urb` %, 직업 `lo/hi` 0~100, `only` 배열, `oriVuln` `{infect, progress}`, 사인 `w` 는 7밴드 배열 `[<1,<5,<15,<30,<50,<70,70+]`. `prepareData()` 가 전부 정규화하므로 명세 §3 표를 W1 형식으로 갱신해 두면 좋다.
- `policy` 는 문자열 하나이고 분할 정책은 `policyVariants:[{when, policy}]` 다. `when` 은 `year>=1098` / `urban==false` / `region=='north'` / `amir=='mining'` 같은 한 줄 비교식이며 엔진이 직접 평가한다. `region`·`amir` 처럼 S 에 없는 변수는 **출생 시 50%** 로 그 값을 받고 나머지는 `'other'` 가 된다(`S.sub`). **[결정]** 북조/남조, 아미르 비율을 데이터에 적을지(예: `policyVariants[].p`).
- 사인 `tags` 의미를 "같은 접두(`threat:`, `nation:`)끼리 OR, 접두 그룹끼리 AND" 로 해석했다(`execution` 의 위협 4개 = 아무거나, `euthanasia` = `infected` AND `nation:leithanien`). W1 `_meta` 는 이 점을 안 적고 있다. **[결정]** W1 과 확인.
- 소수민족은 `nations.json` 의 `ethnicFlags`(`gaul`: victoria 6%, `nomad`: tara 15%) → 엔진이 `nation.eths` 로 변환. `outsider` 는 §5.3 대로 자동.
- `names.json` 은 `langs[lang] = {o, sep, m, f, s, pat, femSurname, noble, doubleSurname, raceRule}`. `src/engine/names.js` 가 전부 지원(부칭은 아버지 이름에서).
- 작은 불일치: `jobs.json` 의 `royal_messenger.risk.court_intrigue` 가 `causes.json` 에 없음(경고만).

### 콘텐츠 스키마(§3.5)
- 전역 `S` 가 없으므로 모든 콜백이 **ctx(sim) 를 첫 인자**로 받는다: `c(ctx)`, `w(ctx)`, `run(ctx)`, `ok(ctx,p)`, `build(ctx,p)`, `apply(ctx,k,p,text)`. §3.5 예시를 이 형태로 고쳐야 W4 가 혼동하지 않는다.
- 결정 스케줄링: 원작은 거대한 `scheduledDecisions()` 하드코딩이지만 여기서는 결정마다 `ok(ctx)` 게이트를 매년 평가한다. 추가 필드 `once`(기본 true), `gap`, `at`, 선택지 `auto`(자동 결정 가중치).
- 이벤트 태그에 `!` 부정 지원(`'!rhodes'`). 태그 목록은 `src/engine/README.md`.
- 초점(FOCUS) 표와 단계별 선택지는 `content/focus.js` 가 아니라 `src/engine/sim.js` 에 두었다(초점 효과가 연말 정산에 묶여 있어서). 문구만 W4 가 바꾸면 된다.
- 잠시 멈춤(5·15·30·50·70세)·캐스터 루트 결정·결혼/자녀 결정은 더미에 없다. 결혼·출산은 엔진 `familyYear` 가 확률로 처리하므로 W4 가 결정으로 바꾸려면 그 부분을 끄면 된다.

### 실행 방법
- 개발: 프로젝트 루트에서 `python -m http.server 8000` → `http://localhost:8000/src/`. `src/` 만 서빙하면 안 된다(`content/dummy.js` 가 `../src/engine` 을, 로더가 `../data/*.json` 을 참조). `.claude/launch.json` 에 `dev` 설정을 넣어 두었다.

### 결정 모달 종류 — W4 가 `build()` 반환값에 넣어야 하는 것
- `view.kind`: `'big'`(기본) | `'small'` | `'reflect'`. 없으면 `view.input` → reflect, `view.small` → small, 결정 id 가 `reflect`/`pause` 로 시작하면 reflect.
- small: 8초 카운트다운 뒤 `view.def`(선택지 k) 또는 첫 선택지를 자동 선택. 창을 누르거나 아무 키를 누르면 카운트다운 정지.
- reflect: `view.q`(질문), `view.ph`(placeholder) 로 textarea 한 줄. 입력 텍스트는 `choose(k, text)` 로 `apply(ctx,k,p,text)` 에 전달되고, UI 가 별도로 `S.journal[] = {a, y, id, text}` 에 쌓아 사망 기록 "돌아보며" 아래에 보여 준다. `tr1.prefs.reflect = false` 면 reflect 결정은 첫 선택지로 즉시 넘어간다.
- 선택지 `sub` 가 효과 힌트 줄이다. 자동 결정이 켜져 있으면 `HOOK.decision` 안에서 바로 `autoChoice()` 한다(모달 없이 로그에 "결정: …" 만 남음).
- 잠시 멈춤 결정(5·15·30·50·70세)은 더미에 없다. UI 는 준비됐으니 W4 가 `kind:'reflect'` 로 넣으면 된다.

### 저장
- `tr1.save = {S, at}`: 매년(`HOOK.year`), 결정 모달이 열릴 때, 결정 직후, 멈춤·나가기, 탭 숨김·언로드. 사망 시 삭제, `tr1.past`(최근 10생 요약)에 추가. `tr1.rolls` = 태어난 횟수(신고 번호 일련번호). `tr1.prefs = {speed, auto, reflect}`.

1. **조사(助詞) 처리**: "미하일와(과) 결혼했습니다" → 받침 검사로 '과/와' 선택하는 유틸이 필요(원작처럼 `eul/iga/ro/eun/wa` 류를 `src/ui/text.js` 또는 엔진 공용으로).
2. **자녀 이름 중복**: 두 아이가 모두 "아나스타시야". 가족 내 이름 중복 제거.
3. **국가 고유 기관명**: 출생 신고서 각주 "우르수스 흠천감 추정" — 흠천감은 염국 기관. 국가별 통계 기관명 필드(`statOrg`)를 nations.json에 두고 각주에 치환(우르수스 "제국 내무성", 컬럼비아 "보험협회" 등).
4. **더미 이벤트 반복**: "학교에서 친구를 사귀었습니다" 매년, "재앙 정보 전달자가 경로를 잘못 읽었다" 3년마다. W4가 실제 풀을 넣으면 해소되지만 `gap`·`rep` 기본값을 보수적으로(gap 4년 이상).
5. **아기 구간 결정**: 5세 잠시 멈춤이 자동 결정 중엔 보이지 않음. 의도대로지만, 자동 결정을 켜도 잠시 멈춤만은 뜨게 할지 결정 필요(원작은 끄기 전까지 뜸).
6. 상단 바가 매년 재렌더되어 DOM 노드가 교체됨(자동화 도구 기준 관찰). 사용자 체감 문제는 없으나 포커스가 튈 수 있으니 W5 폴리시 때 부분 갱신으로.

실행 방법: 프로젝트 루트에서 `python -m http.server 8765` 후 `http://localhost:8765/src/index.html`.

### 남은 거친 부분

- 모바일 하단 시트 모달은 긴 본문·선택지 5개 이상이면 안쪽 스크롤이 생긴다(88vh). 드래그로 닫기·배경 탭 닫기는 없음(결정은 반드시 골라야 하므로 의도).
- 사망 기록 모바일(≤400px)은 요약 셀 12개가 1열이라 세로가 길다. 2열(라벨 짧음)로 되돌려도 깨지지 않으니 취향 문제.
- 출생 신고서 `.rec` 의 값이 긴 경우(부모 한 줄에 직업 두 개) 400~800px 사이에서 두 줄로 접힌다. 전폭(`.w`)은 부모만 줬다.
- 픽셀 장면 슬롯(`.pixel-slot`)은 여전히 빈 프레임. 높이 120px 고정.
- `src/index.html` 의 `<meta name="color-scheme" content="light dark">` 는 그대로(CSS `color-scheme: dark` 가 우선). 빌드 정규식이 그 파일 모양을 보니 손대지 않았다.
- `decision.js kindOf()` 가 아직 `v.small` 플래그를 인정하지만 콘텐츠는 전부 `kind:'small'` 을 쓴다. 한쪽으로 통일해도 된다.
- 스크린샷 스크립트는 세션 스크래치패드(`shot.js`)에만 있고 레포에는 없다(W5b-1 과 동일). 필요하면 `build/verify-death.js` 보일러플레이트에 `Emulation.setDeviceMetricsOverride` + `Page.captureScreenshot` 만 붙이면 된다.
