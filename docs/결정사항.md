# 결정 사항 기록

형식: 날짜 · 결정 · 이유/메모. 뒤집힌 결정은 지우지 말고 "폐기" 표시 후 새 항목 추가.

## 2026-10-19

- **D1. 프로젝트 정체**: 웹게임 「80억 분의 1」(1in8b.life)의 **가벼운 패러디**. 배경은 **명일방주(Arknights)의 테라**. 국가는 시라쿠사·런디니움(빅토리아)·사미 등 인게임 국가, 사건은 오리지늄 아츠 수련·광석병 감염·해사 침략 등 인게임 설정 반영. "헬테라" 분위기가 재미 요소.
- **D2. 영리화 없음**. 결제·유료 기능·광고 일절 없음.
- **D3. 배포 방식**: 서버를 열지 않는다. 명일방주 팬 커뮤니티에 코드 또는 실행 파일을 배포해 각자 로컬에서 실행. → 원작의 `/api/*`(동접·커뮤니티·추모관·결제·기록 옮기기)는 전부 제외.
- **D4. 통계 출처 방침**: 테라 국가는 현실 모델(시라쿠사=이탈리아, 런디니움=영국, 사미=북유럽 사미권 등)이 있으므로 원작이 쓴 현실 통계를 참고 기준치로 쓰되, 광석병·재앙·데몬·해사 같은 테라 고유 위험을 얹는다.
- **D5. 세션 운영**: 이 세션(2026-10-19 시작)은 **논의 전용**. 결정은 이 파일과 세션 메모리에 남기고, 실제 작업은 **작업 전용 세션을 따로 열어** 진행한다.
- **D7. 국가명·용어는 한국 정식 번역명을 따른다**: 용문(룽먼 ✗), 에기르(이지르 ✗), 극동(히가시 ✗). 조사로 추가 확인된 표기: **살카즈**(사르카즈 ✗), **시테러**(해사는 별칭), **고요함**(이베리아의 '대침묵' ✗), 쉐라그, 라이타니엔, 카시미어, 카봐렐리엘키(카시미어 수도), 재앙 정보 전달자, 붕괴체, 위치킹/쌍둥이 여황. 전체 대조표는 `reports/테라 국가 설정 게임 구현 요소.md` 상단 참조. 미확정 표기(시테러/시본, 몬텔루페/몬테루페 등)는 게임 용어집 작성 시 결정.
- **D10 (참고 자료)**: 국가별 설정·공통 메커니즘 조사 보고서 `reports/테라 국가 설정 게임 구현 요소.md`(원 노트는 `research_notes/테라 국가 설정 게임 구현 요소/`). 설계 시 결정이 필요한 12개 항목은 보고서 D절 참조. 특히 **테라인 평균 수명 약 150년(캐논)** vs 현실 1950 생명표 사용 여부는 미결.
- **D8. 타라(Tara) 추가**: 빅토리아의 하위 지역. 현실 영국-아일랜드 대응. 인게임 시점에는 빅토리아에 속해 있다가 독립을 선언한 설정(세부는 조사 후 보강). 공식 설정집 『테라: 대지 여행』을 참고 자료로 삼는다.
- **D9 (잠정). 인구·기본 통계 기준년 = 현실 1950년**: 테라를 현실 몇 년에 대응시키는 공식 설정은 없음. UN 추계 시작점이고 국가 지도가 테라와 가장 잘 겹쳐서 채택. 국가별 출생 비중은 1950년 현실 비중에 0.7제곱 완화 + 서사 보정(염국 25, 우르수스 14, 컬럼비아 12, 빅토리아 9, 라이타니엔 7, 사르곤 6, 극동 5, 시라쿠사 4, 카시미어·이베리아·카즈델 3, 볼리바르 2, 사미·미노스·림 빌리턴 1.5, 쉐라그 1, 라테라노·에기르 0.5, 두린 0.3, 로도스 0.05). 사용자 검토 후 확정.
- **D9 확정**: 1950 기준년과 국가 비중표 채택. 타라는 빅토리아 하위 출생지 분기(빅토리아 9% 중 1.5%), 용문은 염국 하위 분기(염국 25% 중 3%).
- **D11. 수명 척도 = 인간 척도**(1950 생명표 그대로). 캐논 "테라인 평균 150년"은 무시하고, 종족 테이블의 `lifeMul`(수명 배율) 컬럼으로 살카즈·엘프·두린 등 장수 종족만 예외 처리. 사망 기록 각주로 이 사실을 농담처럼 고지.
- **D12. 출생 연도 = 테라력 1080~1100 랜덤**. 캐논 대사건(체르노보그-용문 사변 1096.12, 런디니움 사태 1094~1098, 타라 독립 1098, 라테라노 사변 1101 등)은 `연도 + 나이` 조건으로 게이트. 1102년 이후는 캐논 공백이므로 각국 구조적 긴장을 확률 이벤트로 연장(창작).
- **D13. 극동 감염자 정책(캐논 공백, 창작)**: 남조 = 컬럼비아식 보험·기업형, 북조 = 격리 + 수치 문화(가족이 숨김). 데이터에 `canon: false` 표시.
- **D14. 출생지 풀**: 에기르 0.5%·두린 0.3%는 희귀 출생지로 포함. 로도스 아일랜드는 출생지에서 제외하고 감염 판정 이후 "로도스 합류" 이벤트로만 등장.
- **D15. 돈 표시 단위 = 용문폐(LMD) 환산**. 국가 간 상대값은 1950 PPP 비율 사용. 절대 금액은 창작.
- **D16. 종족**: 약 20종. 국가마다 주종족 1~2개(합 60~70%) + 부종족 2~3개 + 전 세계 공통 소수(살카즈 2~5%, 그 외 1% 미만). 비율은 전부 추정, 플레이테스트로 조정.
- **D17. 출처 충돌 해결 기준**: arknights.wiki.gg 우선, 그중 설정집(『테라: 대지 여행』) 인용 표기가 붙은 항목 최우선. 나무위키 단독 수치는 (불확실) 표기 유지.
- **D18. 작업 세션 입력 문서 = `docs/설계_명세.md`**. 작업 세션은 이 명세와 결정사항만 읽고, 조사 보고서는 특정 국가 콘텐츠를 쓸 때 해당 절만 참조.
- **D19. 기대수명 표기와 완료 기준**: 출생 신고서·통계 카드의 "기대수명"은 1950 모델값이 아니라 **시뮬 기대수명**(모델 − 테라 손실, `test/sim.js`로 산출해 데이터에 캐시). 모델값은 "테라가 아니었다면 N세" 비교 문구로만 쓴다. 엔진 완료 기준은 시뮬 기대수명 기준 ±5, 험한 국가(우르수스 등)는 모델 대비 −10까지 허용. `balance.js`는 W2가 낮춘 값 유지.
- **D20. 정책 변형 비율**: `policyVariants[]`에 `p`(출생 시 해당 변형에 속할 확률) 필드 추가. 초기값 극동 북조 0.4, 시라쿠사 시골 = `urban==false` 그대로, 사르곤 광산 아미르령 0.3, 용문은 연도 조건 유지. 엔진은 `p`가 없으면 0.5.
- **D21. 사인 `tags` 해석** = W2 구현대로: 같은 접두(`threat:`, `nation:`) 끼리 OR, 접두 그룹끼리 AND. `data/README.md`에 명시.
- **D22. `yearSec`는 국가 e0(인간 척도)로 계산**. 장수 종족은 같은 초/년으로 더 오래 산다(희귀하니 허용). W1 메모 9의 "염국 e0가 짧아 플레이가 짧아진다"는 `yearSec = 720/e0`가 보정하므로 문제 아님. `statMul.le` 보정 없음.
- **D23. 콘텐츠 콜백 규약** = W2 구현대로 `ctx` 첫 인자(`c(ctx)`, `run(ctx)`, `build(ctx,p)`, `apply(ctx,k,p,text)`), 결정은 `ok(ctx)` 매년 게이트 + `once/gap/at/auto`. 설계 명세 §3.5 예시를 이 형태로 갱신.
- **D24. 아나티 home** = 사미·쉐라그(보고서 A-5). 사르곤 표의 아나티는 오기 → 아나사로 교체(W1 후속).
- **D25. 제4의 벽·현실 참조·면책 문구 제거(최종본 요구)**: 화면 어디에도 "테라가 아니었다면 N세", "신뢰구간 없음", "민감도는 묻지 마십시오", "환율은 창작", "흠천감 추정", "임시", "D9 기준", "1950년 통계" 같은 메타·현실·추정 표시를 두지 않는다. 각주는 **세계관 안의 출처**로만 쓰고 자신 있게 단정한다(예: "(우르수스 제국 내무성 고시 1097년)"). 통계 출처 설명과 면책은 README·배포 글에만. 시작 화면 면책은 한 줄 "비공식 팬 창작"으로 축소하거나 하단 작은 글씨.
- **D26. 국가 특색 강화(최종본 요구)**: 국가마다 상징 직업이 "적당한 포인트"로 보여야 한다. 카시미어 스포츠 기사, 이베리아 집행관(재판소), 시라쿠사 패밀리 조직원, 컬럼비아 과학자·기업 연구원, 라이타니엔 음악가·아츠 캐스터, 볼리바르 용병, 라테라노 공증인·총기 장인, 림 빌리턴 광부, 사미 눈의 사제, 카즈델 용병, 염국 관료, 용문 근위국, 극동 무사·회사원 등. 비율은 소수(국가 내 5~15%)지만 이벤트·문화 묘사(명절, 호칭, 음식, 통치 방식)에서 국가가 팍팍 느껴지게. 직업 제안 시 국가 특수 직업이 최소 1개는 후보에 들어가게.
- **D27. UI 재설계(최종본 요구)**: 현재 공문서풍 CSS는 "AI slop" 느낌. 최종본은 명일방주풍의 세련된 UI(로도스 단말기·PRTS 느낌: 어두운 바탕, 얇은 선, 산세리프, 기하학적 프레임, 강조색 1~2개, 여백). 공식 에셋은 쓰지 않고 분위기만. W5 폴리시 단계에서 전면 재작업하고, 그 전까지 W4는 UI에 손대지 않는다.
- **D28. 제목 = 금일방주(今日方舟) / 영문 Arkdays**. 시작 화면 카피 "몇 억 분의 1". Arknights 로고 서체·레이아웃은 흉내 내지 않고 글자만. 폴더명은 명생게임 유지. localStorage 접두는 `tr1.` 유지.
- **D29. 배포 형태 = 단일 `dist/index.html`**(더블클릭으로 `file://`에서 동작). JS 모듈과 `data/*.json`을 전부 인라인. 빌드 도구는 Node + esbuild(개발 의존성만, 런타임 라이브러리 0 유지). 커뮤니티 배포는 HTML 1개 또는 zip, 선택적으로 itch.io/GitHub Pages 정적 호스팅.
- **D30. 조사(助詞) 전면 점검(수정 패스)**: 변수가 들어가는 모든 문장("필라인는 흔하지 않는 종족입니다" 등)에서 은/는·이/가·을/를·와/과·으로/로가 받침에 따라 붙도록. `src/engine/text.js` 유틸을 UI 템플릿(`src/ui/text.js`, 출생 신고서·사망 기록 포함)과 모든 콘텐츠 파일에 일괄 적용하고, 테스트 스크립트로 "[가-힣]는 |[가-힣]를 " 같은 오용 패턴을 grep해 0건 확인.
- **D31. 각주 빈도 축소(수정 패스)**: "각주 100%" 기준 폐기. 각주는 **실제 통계처럼 보이는 숫자가 있을 때만**, 전체 이벤트의 10~20%. "○○는 ○○의 관할이 아닙니다" 같은 출처 없는 메타 각주, 내용 없는 각주는 전부 삭제. 결정 모달의 `fact`도 같은 기준. 사망 기록·출생 신고서의 통계 비교 문장은 유지(원작의 핵심 장치).
- **D32. 수정 패스 운영**: W4·W5 일단락 후 D25·D30·D31과 플레이 피드백을 모아 한 세션에서 일괄 수정. 그 전까지 콘텐츠 세션은 기존 기준으로 진행하되 새로 쓰는 각주는 D31을 따른다.
- **D33. 징병은 기본 남성만(수정 패스)**: 현재 `draft18` 결정과 엔진 `mandatory` 처리에 성별 조건이 없어 여성도 소집됨(버그). `nations.json`에 `conscriptSex: 'M' | 'all'` 추가, 기본 `'M'`, 볼리바르(싱가스 성별 무관 의무복무 캐논)만 `'all'`. 라테라노 총기 의무는 징병이 아니므로 무관.
- **D34. 잠시 멈춤(5·15·30·50·70세 생각 남기기) 제거(수정 패스)**: 결정 `pause5/15/30/50/70`과 `elder_pause70`, 상단 바 토글, `S.journal`, 사망 기록의 journal 표시, 공유 텍스트의 인용을 전부 제거. 12분 플레이에 흐름을 다섯 번 끊을 가치가 없고 결정처럼 오독됨. 엔진의 `kind:'reflect'` 모달 처리는 남겨 둬도 되지만 UI 토글은 지운다.
- **D35. 가사 전담(전업주부) 구현(수정 패스)**: `jobs.json`에 `homemaker`(가사 전담, 소득 0)가 있지만 엔진·콘텐츠·UI 어디서도 쓰지 않아 실제로는 미구현. 구현안: 직업 제안이 아니라 **상태**로. 결혼 또는 첫 자녀 때 `adult_homemaker` 결정(가사를 맡는다/일을 계속한다)을 열고, 기본 가중치는 `nations.json`의 `homemakerP`(1950 현실 모델 기준 기혼 여성 가사 전담 비율을 국가별로 추정: 전통 사회 0.7~0.8, 컬럼비아·극동 남조·용문 0.4~0.5, 사미·카즈델·볼리바르 등 생계형 0.3)와 성별(남성은 ×0.1)로. 가사 전담 중엔 `S.job='homemaker'`, 본인 소득 0, 가계 소득 = 배우자 소득, 자녀 관계·행복 보정 +, 사별·이혼·배우자 실직 시 `adult_backtowork` 결정. 사망 기록 요약은 "가사를 맡았습니다". 신원 카드 직업란 "가사 전담". 추가로 `jobOffers()`가 `sector:'none'` 직업을 제안 후보에서 제외해야 하고(지금은 소득 0짜리 `homemaker`가 미혼 남성에게도 제안될 수 있음), 엔진에 **배우자 소득이 가계에 합산되는 경로가 없음**(`fam.partner.inc`를 finance가 읽지 않음)도 같이 고친다.

- **D39. v0.3 방향 = 진로(track)·소속(affiliation) 시스템**: 배포 후 사용자 평가 — 원작의 "근대 샐러리맨 생애 주기"를 테라 명사로 치환한 수준이라 모든 나라에서 취직→승진→은퇴를 함. 직업 id + 소득 drift 대신 **국가별 진로 상태 기계**(단계·칭호·분기·결말)와 **소속 집단**(패밀리·군단·교황청·라인 랩 등)으로 교체하고, 출생 계층이 진입구를 정하며, 로도스 아일랜드는 진로가 아니라 "출구". 프린세스 메이커식 인생역전·명문 입사 성공담은 지양, "뜻대로 안 되는 방식이 나라마다 다름"을 목표로. 조사 결과는 `docs/진로_소속_초안.md`(원형 12개, 21개국 + 공통 고용주, 능력치 역산, 결정 필요 항목). **능력치 체계는 초안 §23을 보고 별도 논의 후 결정.** 배포본 운영은 신경 쓰지 않음(핫픽스 불필요, 커뮤니티 피드백은 v0.3에 반영).
