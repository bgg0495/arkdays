# 금일방주 · Arkdays

테라의 어딘가에서, 누군가로, 한 번. 명일방주 세계관 위에서 무작위로 태어나 한 생을 살아 보는 브라우저 인생 시뮬레이션입니다.

**플레이**: [index.html](index.html) 파일 하나를 브라우저로 열면 됩니다. 설치·서버·회원가입 없음. GitHub Pages로 열면 주소는 `https://<사용자>.github.io/arkdays/` 입니다.

- 출생 국가(염국·우르수스·빅토리아·카시미어·시라쿠사·사미…)와 종족, 가정 형편은 고를 수 없습니다.
- 한 해씩 흐르며 진학·일·결혼·감염·재앙·징집 같은 갈림길에서 선택합니다. 자동 결정도 됩니다.
- 광석병, 재앙, 시테러, 붕괴체, 내전처럼 테라에만 있는 위험이 통계대로 찾아옵니다.
- 끝나면 사망 기록이 남고, "복사하기"로 전부 복사해 공유할 수 있습니다.
- 저장은 브라우저 localStorage에만 남습니다. 어떤 데이터도 어디로도 보내지 않습니다.

## 면책

「명일방주(Arknights)」(© Hypergryph / Yostar)의 세계관과 용어를 빌린 **비공식 팬 창작물**입니다. 공식과 아무 관련이 없고, 공식 일러스트·음원·텍스트는 쓰지 않았습니다. 설정에 없는 숫자(감염률, 재앙 빈도, 종족별 수명 등)는 전부 제작자가 지어낸 추정치입니다.

게임의 뼈대인 "무작위로 태어나 한 생을 통계로 살아 본다"는 아이디어와 출생 신고서 → 인생 → 사망 기록 흐름은 웹게임 **「80억 분의 1」(1 in 8 Billion, [1in8b.life](https://1in8b.life), 제작 진휘어스)**에서 강하게 차용했습니다. 코드·문구·그림은 그 게임 것을 가져오지 않고 전부 새로 만들었습니다. 원작을 아직 안 해 보셨다면 그쪽을 먼저 권합니다.

영리 목적이 없습니다. 광고·결제·후원 없음. 권리자(Hypergryph, Yostar, 1in8b.life)의 요청이 있으면 내리겠습니다.

## 개발

```bash
npm install          # esbuild 하나뿐
npm run build        # dist/index.html 과 루트 index.html 생성
npm run check        # 데이터 검증 · 조사/금지 문구 검사 · 300명 자동 시뮬
npm run verify       # headless Chrome 으로 file:// 플레이 검증(12세까지)
npm run verify:death # 사망 화면까지 3생
```

개발 중에는 프로젝트 루트에서 `python -m http.server 8765` 후 `http://localhost:8765/src/index.html`.

```
data/      국가·종족·직업·사인·이름·통계 JSON
content/   이벤트·결정·대사건·사망 텍스트 (index.js 가 조립)
src/engine 시뮬레이션 코어 (UI 없이 Node 에서도 돌아감)
src/ui     화면 5종 + CSS
build/     단일 HTML 빌드와 검증 스크립트
test/      자동 시뮬·데이터 검증·텍스트 검사
docs/      결정 기록(결정사항.md), 설계 명세, 조사 자료
release/   배포 스냅샷
```

설계와 결정 이력은 [docs/결정사항.md](docs/결정사항.md)와 [docs/설계_명세.md](docs/설계_명세.md)에 있습니다. 국가·종족 설정 조사는 [reports/](reports/)에 있습니다.
